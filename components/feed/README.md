# components/feed

Feed-specific presentation components, all fed by `app/_data/mock.ts`:

- `FeedHeader.tsx` — room label, greeting and room subtitle.
- `Composer.tsx` — “Compartí un momento…” entry point with the current user avatar.
- `PostCard.tsx` — post card with type badge (LOGRO / ACTIVIDAD / ANUNCIO), audience, body, optional photo placeholder and like/comment counters.
